# Security policy

## Supported versions

The `main` branch is the currently supported development line. Published
release support will be documented here when the first release is published.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub's
private vulnerability reporting or a private contact to the repository owner.

Include the affected version or commit, reproduction steps, impact, and any
suggested mitigation. Please redact Discord tokens, Gemini API keys, message
content, and other private data from reports and logs.

We will acknowledge a valid report, investigate it, and coordinate disclosure
after a fix or mitigation is available.
