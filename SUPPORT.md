# Support

Use the channel that matches the request:

- Usage and design questions: [GitHub Discussions](https://github.com/TakalaWang/twlinter/discussions)
- Reproducible bugs: [GitHub Issues](https://github.com/TakalaWang/twlinter/issues)
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md)

When reporting a bug, include the TWLinter commit or release, operating system,
input type, command or adapter used, and a minimal redacted reproduction.
Never include Discord tokens, Gemini keys, or private message content.
